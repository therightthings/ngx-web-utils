# @trt-web/vue

## Introduction

- `@trt-web/vue` provides reusable, strongly typed building blocks for Vue applications.
- Use the package to keep shared UI and application patterns consistent across Vue projects.

---

**Install**

```bash
npm install @trt-web/vue
yarn add @trt-web/vue
bun add @trt-web/vue
```
